# Lista de regresión manual

1. Iniciar con `npm run dev` y comprobar que aparecen las recetas.
2. Seleccionar cada tipo de espacio y asignar una receta compatible.
3. Cambiar y quitar una receta; usar **Deshacer**.
4. Crear una semana automática y recargar: el menú debe persistir.
5. Buscar y filtrar por tiempo, proteína y favoritas.
6. Abrir una receta y revisar ingredientes, cantidades e instrucciones.
7. Crear, editar, duplicar, marcar favorita y eliminar una receta personal.
8. Cambiar el multiplicador de porciones y comprobar la suma en compras.
9. Exportar, limpiar e importar el respaldo; una entrada inválida debe mostrar error.
10. Denegar el portapapeles y comprobar que aparece texto seleccionable.
11. Recorrer botones, filtros, espacios y diálogo solo con teclado; Escape debe cerrar.
12. Ejecutar `npm run build`, abrir `npm run preview`, instalar la PWA y probar una recarga sin conexión.
